## 🚀 Proyectos Destacados

### 🔍 Comparador Automático del Plan de Producción — *Kaizen*
Herramienta web que mapea líneas de un archivo Excel tomando como referencia los encabezados, y compara el **plan de producción vs. lo ejecutado**.

- Detecta variaciones en cantidades y cambios no reportados por Planeación.
- Utilizada a diario por el área de **Mejora Continua**.
- Beneficia a **Producción y Almacén**.

**Stack:** `HTML` · `JavaScript` · `Excel`
